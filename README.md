# Git Intro Assignment

This repository is my assignment for the hands-on Git and GitHub workshop conducted by Dr. Muhammad Wasim at UMT (Sialkot Campus).

## Purpose

This project demonstrates my understanding of basic Git and GitHub concepts, including:

- Creating and cloning a GitHub repository using HTTPS
- Making and tracking commits
- Using `.gitignore`
- Managing files and changes with Git
- Pushing changes to GitHub
- Viewing commit history

## Files

- `README.md` - Project description
- `.gitignore` - Files and folders ignored by Git
- `notes.txt` - Notes about Git basics
- `hello.py` - Simple Python greeting program
